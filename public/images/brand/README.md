# Nostos wordmark assets

Source: the supplied `codex-clipboard-ebe233c4-8e73-431d-abc3-de39487a3601.png` brand artwork.

The source was cropped to the artwork area with a small transparent safety margin. The exported canvas is **1484 × 286 px** (approximately **5.19:1**), using the same intrinsic dimensions for the light and dark placements. The warm presentation background was removed with a soft near-background key; the black strokes and lilac inner accent remain in the artwork.

- `nostos-wordmark-inverse.png` — same dark-surface treatment as the dark PNG, 1484 × 286 px.
- `nostos-wordmark-inverse.webp` — lossless transparent WebP dark-surface treatment, 1484 × 286 px, approximately 34 KB.
